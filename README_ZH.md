## 将太阳能电池转化为建筑表皮制造技术

BIPV 不仅需要实验室效率，还需要适用于幕墙、窗户、屋面、曲面和既有建筑轻量化改造的制造体系：

- 兼容高分子薄膜基材的轻量结构；
- 不损伤完整多层器件的低温工艺；
- 面向大面积的连续生产；
- 可调透明度和半透明度的光学设计；
- 消除中断卷对卷生产的真空沉积环节。

Cools 将电极、钙钛矿成膜、选择性溶剂去除、缺陷钝化和在线状态控制整合为一个无真空制造平台。

> **目标并非单独制造一片钙钛矿电池，而是连续制造太阳能建筑表皮。**

## 核心制造链

```text
高分子建筑表皮基材
→ 溶液法功能层与光学层
→ 化学镀超薄金属下电极
→ 状态判定型钙钛矿涂布与结晶
→ 配位残留溶剂的共振波长选择去除
→ 缺陷位点选择性钝化
→ 转移层压上电极与封装
→ 无真空卷对卷成品
```

## 1. 无真空沉积层的器件堆栈

所有固体层均来源于溶液涂布、水相化学镀或转移层压片材。器件制造链中不采用溅射、真空蒸发和化学气相沉积（Chemical Vapor Deposition，CVD）。

代表性结构包括：

- 高分子薄膜基材与阻隔层；
- 溶液法介电光学匹配层；
- 胺功能界面层；
- 电连续的化学镀铜或银超薄电极；
- 溶液法电荷传输层；
- 溶液法钙钛矿吸收层；
- 转移层压上电极片；
- 与电极片一体化的薄膜封装。

该结构直接面向轻量、柔性和半透明 BIPV，而不仅是传统重型玻璃组件。

## 2. 基于膜状态的三区钙钛矿工艺

将传统烘箱中被单一温度曲线绑定的三种功能分离：

| 区域 | 主导功能 | 交接判据 |
|---|---|---|
| 第一区 | 通过气相传质去除自由溶剂 | 自由溶剂信号低于阈值、配位溶剂仍保留 |
| 第二区 | 选择性去除配位溶剂 | 配位溶剂峰低于阈值、最终晶相尚未显著形成 |
| 第三区 | 平衡升温完成相变与晶体生长 | 目标晶相达到规定状态 |

区间交接依据红外光谱、光学厚度和晶相等可测膜状态，而不是仅依据时间和烘箱温度。

## 3. 配位 DMSO 的共振波长选择去除

自由溶剂干燥后，二甲基亚砜（Dimethyl Sulfoxide，DMSO）仍可能以配位状态留在铅卤化物中间相中。传统方法通过加热整个膜和基材来去除。

Cools 将纳秒中红外脉冲波长对准干燥膜中实测的配位溶剂振动吸收峰，并将单脉冲热扩散限制在薄膜厚度内。

```text
实测配位溶剂吸收峰
→ 波长对准
→ 纳秒热约束
→ 配位键释放与溶剂脱附
→ 吹扫和抽取
→ 光谱终点确认
```

目标是在最终结晶前去除配位溶剂瓶颈，同时使膜和高分子基材的时间平均温度低于劣化起始温度。

## 4. 表面成核触发与垂直结晶

针对喷墨或狭缝涂布膜，工艺分为：

1. 在自发成核前完成均匀浓缩；
2. 通过低动量干燥气刀等方式扫描表面成核线；
3. 使晶体从表面向基材方向定向生长。

目标是在抑制咖啡环厚度差的同时，形成贯穿膜厚方向的柱状晶粒并降低水平晶界密度。

## 5. 双波长缺陷位点交换与钝化

配位溶剂去除后，表面、晶界和界面可能残留未配位铅缺陷。Cools 将选择性去除进一步扩展为缺陷位点交换：

```text
第一波长：去除占据缺陷位点的配位含氧物种
→ 光谱终点判定
第二波长：激活自由含氧配位体
→ 优先捕获并锚定于暴露的未配位金属位点
→ 锚定引起吸收峰移动
→ 驱动波长吸收下降
→ 自终止
```

钝化物定位于缺陷点，而不是形成覆盖整个电荷传输界面的连续绝缘膜，从而兼顾缺陷钝化和正常晶格表面的载流子传输。

## 6. 在线光谱闭环制造

生产线围绕可测化学和结构状态运行：

- 处理前测量目标物种残留量和峰位；
- 前馈设定波长、脉冲数、扫描速度和局部剂量；
- 处理后判定残余吸收峰终点；
- 独立监测膜损伤指标；
- 沿卷材宽度或基板区域进行空间分辨补偿；
- 只对未达标区域进行选择性再处理；
- 根据累积历史更新配方。

这使固定时间—温度配方转变为光谱闭环制造系统。

## BIPV 应用方向

- 轻量化建筑外墙组件；
- 半透明光伏玻璃；
- 幕墙和窗间墙一体化；
- 曲面与非平面建筑表面；
- 屋面和雨棚薄膜；
- 既有建筑改造用太阳能表皮；
- 可设计颜色和透光率的建筑光伏面板。

## 战略信息

> **钙钛矿真正适合建筑的时刻，不是简单放大实验室电池，而是从一开始就围绕建筑表皮重新设计制造工艺。**

Cools 通过低温化学、无真空电极、波长选择加工、膜状态控制和卷对卷集成，提出面向 BIPV 的专用制造路线。
